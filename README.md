# Oficina · Monitoreo (pixel art)

Oficina de **visualización / monitoreo**: solo muestra qué hacen Calleros (laptop) y Terrazas (tableta Android) y en qué sección están. No es una oficina de trabajo y no se edita nada desde aquí.

- Este repo es público y **no tiene datos**: solo el dibujo.
- El estado vive en un repo **privado**. El teléfono lo lee con una llave de solo lectura que viene en el QR de Calleros. Sin esa llave la página no muestra a nadie.
- para-dragtrim/ contiene el aviso que usa la tableta de Terrazas (hook de Claude Code).
